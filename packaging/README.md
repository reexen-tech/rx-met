# 应用发布模板

本目录维护面向用户的安装脚本和使用文档模板。发布构建读取这些模板，生成应用包。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `README.md` | 本目录的维护、授权和审核规则 |
| `release-bundle/install.sh.in` | 唯一用户安装入口模板，打包时内嵌镜像身份和自检代码 |
| `release-bundle/README.md.in` | 安装、数据准备、Docker 挂载和示例运行说明模板 |

发布包的 `CHANGELOG.md` 从仓库根目录提取当前版本内容。公共 runtime 可由本地镜像、
离线 `images/` 或配置的固定 HTTPS 地址提供。构建流程见
[发布说明](../docs/Release_packaging.md)。

## 修改授权

以下规则适用于本目录及所有子目录中的文件和文档，包括本 README：

- **未经用户明确授权，不允许自动修改。** AI 代理、脚本、批量替换和格式化工具不得
  擅自新增、删除、移动、重命名、覆盖或改写本目录内容。
- 其他模块的修改不构成对本目录的授权。即使需要同步文件名、路径、命令或说明，
  也应先列出建议修改的位置和原因，由用户手动修改或单独明确授权。
- 授权仅限用户指定的文件和修改范围，不延伸到其他文件或后续自动同步。
- 获得授权后，必须保留用户已有修改，并提供可审查的差异。
- 发布构建可以读取和渲染模板，将结果写入发布输出目录，不得擅自回写本目录的源文件。

## 审核要求

本目录内容直接影响用户安装和运行流程，修改后必须审核清楚才能纳入发布：

- 安装命令、Docker 挂载、模型与数据路径、示例入口和输出目录必须与实际行为一致。
- 版本、CUDA 变体、runtime 身份和模板占位符必须正确，生成后的命令应可直接执行。
- 核对完整差异，确认仅包含已授权的修改，并完成与修改范围相符的验证。
