# llama.cpp 官方仓库同步与合入流程

本仓库 `origin` 指向内网仓库 `ssh://git@192.168.30.203:2222/zcx17722965607/llama.cpp.git`，官方仓库 `https://github.com/ggml-org/llama.cpp.git` 作为 `upstream`。  
每次需要把官方 `upstream/master` 的更新合入本仓库 `main` 时，统一先从 `main` 拉出临时分支，在临时分支完成合并和冲突解决，再提交到内网并发起 PR。

> 若当前目录已有未提交修改，建议新建独立目录重新拉取仓库，并在新目录中执行以下同步与合入流程。

## 一次性配置

```bash
cd llama.cpp
git remote add upstream https://github.com/ggml-org/llama.cpp.git 2>/dev/null || git remote set-url upstream https://github.com/ggml-org/llama.cpp.git
git remote -v
```

## 每次同步

```bash
cd llama.cpp

BRANCH=sync/upstream-master-$(date +%Y%m%d)

git fetch origin
git fetch upstream master

git checkout main
git pull origin main

git checkout -b "$BRANCH"
git merge upstream/master
```

## 冲突处理

```bash
git status
git diff --name-only --diff-filter=U
```

解决冲突后执行：

```bash
git add <file>
git commit -m "Merge upstream/master into sync branch"
```

## 检查

```bash
git status
git diff origin/main...HEAD --stat
git log --oneline --graph -20
```

## 推送并提 PR

```bash
git push -u origin "$BRANCH"
```
