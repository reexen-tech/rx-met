# ONNX 全连接在校准前统一为单一输出量化边界

- 状态：已接受
- 日期：2026-11-17

## 背景

PyTorch 标准 `nn.Linear` 完成 `xW+b` 后量化一次输出，RX 导出器将其保留为
Gemm。直接输入 ONNX 时，同一计算可能表示为 MatMul 与 Add，逐节点校准会在
加 bias 前额外量化一次。Po2 可能将两处 scale 映射为相同值，但不能移除中间
舍入；既有编译器融合约定还会拒绝两端不同的量化类型。

KWS 历史对比中的全连接为 Gemm，后续改成 1×1 Conv，没有覆盖拆分全连接。
单独验证 bias 乘积 scale、文件编码格式或相同模拟图的重载也无法发现该差异。

## 决策

ONNX PTQ 在创建 QuantSim 前识别安全的常量全连接，将二维输入规范为 Gemm，
高维静态输入规范为 Reshape、Gemm、Reshape。输入和输出 Reshape 仅改变形状，
不增加独立量化点；最终输出量化器拥有唯一的全连接输出网格。

首版限定标准 ONNX FP32、静态正维度、initializer 权重 `[K,N]` 与 bias `[N]`。
中间结果不得有旁路或作为模型输出。无法证明这些条件的图保持原语义，目标导出
不能支持时明确拒绝，不通过改写 JSON 或强制 scale 相同绕过。

规范图、原节点别名和形状映射保存在 ONNX metadata 中。输入、参数和最终输出的
配置映射到实际量化器，导出、重载和验证共同使用规范图。显式内部端口配置、
不可等价保留的 supergroup 与共享 bias 累加器网格冲突在修改前拒绝。

全连接边界不依赖 Po2；bias 校准遵守已有配置，启用乘积 scale 对齐时继续满足
`Sb = Sx * Sw`，保留显式关闭 bias 的设置。

## 数值验收

原图作为独立浮点参考。完整工作流使用所有校准和验证样本检查 FP32 规范化，
要求有限值且满足 `atol=1e-6, rtol=1e-5`，超限失败，不自动放宽。
此门槛只用于图规范化；规范图到 Clean ONNX 的输出仍须精确相同，量化网格重载
和量化数值回归继续采用自身的严格验收。PTQ 与 Po2 分别记录和验收。

## 备选方案

- 仅启用 AIMET MatmulAdd pass：它关闭中间输出，但当前 bias 生命周期及混合
  精度输出配置没有同步迁移，且旧编译器的编码位置约定仍不匹配。
- 保留拆分图并引入逻辑 Linear 组：需要配置、模拟、编译器映射和重载共同支持
  跨节点边界；当前使用真实 Gemm 可以复用已验证的全连接处理。
- 导出时删除一个编码或移动 scale：不能撤销模拟器已执行的中间舍入，且可能把
  post-bias 编码标到实际 pre-bias 张量上，因此不采用。

## 影响

原始文件、参数值和模型输入输出接口保留，导出 ONNX 的内部结构会变化。
必须重新量化生成配套 ONNX 和 JSON，不能复用旧编码套在规范图上。
本次规则不更改 PyTorch 路径、Po2 算法或编译器实现。
