# ONNX 输入与复合表达式的量化域归属

- 状态：已接受
- 日期：2026-11-17

## 背景

Torch 模块使用消费者输入量化器，Python 数学标量不经过 Tensor QDQ；原生循环
层拥有自己的内部网格。逐张量的 ONNX 量化器不能直接覆盖所有这些边界。
独立重载同一模拟图也无法发现图与编译器全局参数域的表达差异。

## 决策

循环层与普通消费者共享数据时，普通消费者使用端口局部网格。图输入及其纯数据
移动链由 native 输入域和消费者域分别拥有；若来源是真正的计算节点，其输出
量化保留，再为普通消费者增加独立输入域。

严格识别完整 FP32 标准 GELU erf/tanh 公式的数学常量端口，复用已有控制值的
原值旁路机制。只豁免这些端口，不全局关闭普通标量参数或共享常量的其他用途。
同图同值的冻结可训练 GELU 系数无法凭 ONNX 推断来源，按标准公式的数学常量
解释；非标准系数、dtype、旁路或不完整公式不自动套用此规则。

eval Conv→BN 遵守 Torch 的源参数域：Conv 参数先 QDQ，BN 以浮点参数计算，
最终量化位于 BN 输出。不能把原始浮点 W 先折叠后再校准，声称与原量化流程等价。

## 编译器表达限制

共享数学字面量若在普通数据域被量化成另一数值，仅省略数学端口编码不足以表达
raw/data 两种用途。旧编译器会按张量名使用全局参数网格；因此此类导出明确拒绝。
字面量在数据网格中精确不变时可继续导出。

旧编译器前端会折叠浮点 BN，不能保留已量化源参数再执行 BN 的顺序。未折叠组
仍可正确模拟，但编译器 JSON 导出须拒绝并提示在浮点模型中预折叠 BN 后重新
校准。源参数域全浮点或原图已折叠的情况不受该保护误伤。

不把这两类限制通过修改量化 scale、预物化常量或放宽输出容差隐藏。

## 验证

使用相同固定网格的真实 Torch QuantSim 参考，并覆盖 native 共享分支、纯移动链、
真实生产者域、GELU 两公式、共享字面量和 ConvBN 源参数域。Po2、导出和重载
分别验证；不能被旧编译器表达的域需要可复现的拒绝回归。

本次不修改一般 JSON2 优先级、InstanceNorm alias 或 LSTM 旧字段兼容策略。
